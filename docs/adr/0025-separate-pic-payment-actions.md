# Separate PIC payment-review and reminder actions

For finalized Campaigns, the PIC dashboard will distinguish Donors whose paid Bukti Transfer needs verification from Donors who have not uploaded proof and need a reminder. Pengingat pembayaran is prioritized before Bukti Transfer perlu ditinjau so the primary action and counts reflect the PIC's chosen operational order; a proof-review CTA must never route a PIC to an unpaid Donor. The dashboard presents the two states as separate actions and counts, hides empty states, and promotes the remaining state when it is the only one. The reminder CTA scrolls to the Donor list, where unpaid Donors are ordered first and the PIC chooses an individual WhatsApp reminder. The proof-review CTA scrolls to the first matching paid Donor with Bukti Transfer awaiting review, using the existing Donor list order: unpaid Donors first, then highest Tagihan. A jump target receives focus and a temporary visual highlight, with reduced-motion behavior respected. When both action counts are zero, the dashboard shows a completion message without a primary action and keeps the Donor list secondary. Any paid-but-unverified record remains in the review state even when its proof link is missing; the card shows a missing-proof warning and no verification controls.
