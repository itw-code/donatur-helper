# Require a real-data acceptance gate for Phase 1

**Status:** accepted

Phase 1 is complete only when Donor and PIC capabilities work against the real local/test account data, mobile and desktop workflows pass, automated checks pass, and no critical or high-severity regression remains. Deterministic fixtures may support automated checks, but they do not replace real-data validation. The next phase requires explicit manual approval of the Donor/PIC experience after those checks; passing static tests alone is insufficient.
