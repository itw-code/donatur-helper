# Donatur Helper mobile UI/UX prototype

**THROWAWAY PROTOTYPE — not production code.**

Question: what should the agreed mobile-first direction look like compared with the current UI?

Run from the repository root:

`powershell
python -m http.server 4173 --directory prototypes/mobile-ui-ux
`

Open `http://localhost:4173/?variant=donor`.

Variants: `donor`, `pic`, and `admin`.
Use the switcher arrows or left/right arrow keys to compare roles.
